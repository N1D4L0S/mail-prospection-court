# mail-prospection-court

Un skill Claude Code pour écrire, réécrire ou tester A/B un mail de
prospection court, en français, envoyé en volume depuis un outil de mailing.
Registre, trame, construction des arguments, personnalisation par attributs,
objet, vérifications avant envoi, traitement des retours. Validé sur une
campagne réelle de démarchage d'enseignes.

## Installer

```
npx skills add N1D4L0S/mail-prospection-court
```

## Contenu

`skills/mail-prospection-court/SKILL.md`, un seul fichier, sans dépendance.
